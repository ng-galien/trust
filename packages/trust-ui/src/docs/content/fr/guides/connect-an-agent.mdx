---
title: "Connecter un agent"
summary: "Empaqueter le skill, le donner à un agent, engager un Plan live, le suivre."
order: 4
---

<Steps>
  <Step title="Lancer le runtime et l'interface">`npm run dev` démarre le runtime (`127.0.0.1:4318`) ; `npm run dev:web` l'interface. Publiez les Procédures et configurez les Environnements dont l'agent aura besoin (valeurs : `workspaceRoot`, URL de services…).</Step>
  <Step title="Empaqueter le skill">`npm run package:skill` → `packages/trust-runner/dist/skill/trust` : `SKILL.md`, `references/results.md`, `scripts/run.js`, `scripts/mcp-stdio.js`. Donnez ce répertoire à l'agent comme skill.</Step>
  <Step title="Pointer le Runner vers le runtime">Définissez `TRUST_RPC_ENDPOINT` et `TRUST_OTLP_ENDPOINT` si le runtime n'est pas local. Ajoutez des options de démarrage répétables `--path <absolute-directory>` seulement si les commandes Shell ont besoin de répertoires d'exécutables supplémentaires.</Step>
  <Step title="Donner à l'agent les outils MCP du runtime">Le runtime sert MCP sur `POST /mcp` pour lire les Plans et les Checks, engager, faire des déclarations et escalader. Ces outils sont nécessaires avec l'un ou l'autre adaptateur du Runner.</Step>
  <Step title="Choisir l'adaptateur du Runner">Pour chaque Check, le harness lance soit `scripts/run.js` comme processus ponctuel et lit son JSON, soit `scripts/mcp-stdio.js` comme serveur MCP stdio local maintenu par l'hôte de l'agent. Le second adaptateur expose seulement `trust_check_run {checkUri}` ; il ne remplace pas le MCP du runtime et l'empaquetage du skill ne l'enregistre pas automatiquement.</Step>
  <Step title="Engager un Plan live">Barre latérale → **Plans** → **Engager un plan** : Procédure, Environnement, identifiant, entrées racines. Confiez le Plan à l'agent (n'importe laquelle de ses URI de Check, ou laissez-le engager via MCP).</Step>
  <Step title="Suivre">La page du Plan se met à jour en direct : verdicts, raisons, Checks rouverts. L'agent lit le Plan après chaque résultat et choisit le prochain Check actionnable. Quand le travail est terminé, **Fermer la session**.</Step>
</Steps>
