Même Procédure, mêmes Checks, même admission, même qualification, même cascade, même historique. Un dry-run est la façon de répéter une Procédure — son ordre, ses gardes de qualification, ses raisons — avant qu'un agent ne l'exécute pour de vrai. Voir [Plans, Sessions et dry-runs](/docs/plans).
