order: 3
---

```gherkin fragment title="One sentence for every HTTP method"
    When HTTP "<name>" sends "GET" to Environment "<url>" and reads Text
    And  HTTP "<name>" sends "QUERY" to Environment "<url>" appending Input "<a>" and literal "search" with query "<name>" from Input "<c>" with header "accept" as "application/json" with JSONata body and reads JSON
    And  HTTP "<name>" sends "POST" to Environment "<url>" with Input as JSON body and reads JSON
```

## Requête

| Partie | Règle |
| --- | --- |
| `"<name>"` | lower camel case, unique dans l'Opération |
| `sends "<METHOD>"` | une méthode applicative enregistrée, dont `QUERY` de la RFC 10008 ; `PRI` et le token réservé `*` ne sont pas des requêtes applicatives |
| `to Environment "<url>"` | requis ; la valeur d'Environment doit être de type `url` |
| `appending Input "<a>"` / `and literal "<segment>"` | segments de chemin encodés optionnels, dans l'ordre |
| `with query "<name>" …` | optionnel et répétable ; valeur d'un Input, d'un Environment `string` ou d'un littéral |
| `with header "<name>" …` | optionnel et répétable ; valeur d'un Input, d'un Environment `string` ou d'un littéral |
| `with Input as JSON body` | l'Input typé complet, encodé en JSON |
| `with JSONata body` | un DocString JSONata fermé, évalué juste avant la requête ; il peut lire les étapes précédentes et utiliser `$assert` pour arrêter avant une mutation |
| `with Text body …` | Text provenant d'un Input, d'un Environment `string` ou d'un littéral |
| `and reads JSON` / `Text` / `no body` | JSON analysé, Text opaque ou corps de résultat volontairement vide |

Les clauses sont ordonnées : chemin, query, headers, corps optionnel, réponse. Les valeurs de chemin
et de query sont encodées dans l'ordre de la phrase. Une URL de base ne peut pas déjà porter une
query si la phrase en déclare une. Les headers refusent CR, LF et NUL ; les corps Text peuvent être
multilignes. Il n'y a pas d'interpolation libre d'URL.

`CONNECT` utilise l'autorité de l'URL d'Environment comme cible de requête et accepte des headers,
mais aucun chemin, query ou corps. Son URL ne doit contenir ni chemin ni query. Le Runner enregistre
le handshake puis ferme le tunnel, car une étape d'Opération est une requête bornée.

```gherkin fragment
    When HTTP "issue" sends "GET" to Environment "jiraIssueUrl" appending Input "issue" and reads JSON
    Then Produce with JSONata
      """
      { "issue": input.issue, "summary": steps.issue.body.summary, "workflowStatus": steps.issue.body.workflowStatus }
      """
```

```gherkin fragment title="GET <issuesUrl>/<issue>/comments?limit=5&run=<run>"
    When HTTP "comments" sends "GET" to Environment "issuesUrl"
        appending Input "issue" and Input "resource"
        with query "limit" as "5"
        with query "run" from Input "run"
        and reads JSON
```

## Statuts

La plage acceptée par défaut est `200`–`299`. Une Opération peut la remplacer par des statuts
terminaux exacts :

```gherkin fragment
    And HTTP "response" accepts statuses
      | status |
      | 200    |
      | 404    |
```

```gherkin operation id="healthcare.admission-record" title="healthcare.admission-record — POST l'Input, lire la réponse"
# language: en
@trust-dsl:1 @operation:healthcare.admission-record @version:1.0.0
Feature: Record one simulated patient admission

  Background: Operation interface
    Given Environment
      | name         | type |
      | admissionUrl | url  |
    And Input
      | input              | type      | cardinality |
      | patient            | reference | one         |
      | admission          | reference | one         |
      | documents          | reference | many        |
      | documentRecordedAt | instant   | many        |
    And Produced fields
      | field           | type      | cardinality | domain                      |
      | admission       | reference | one         | any                         |
      | admissionStatus | string    | one         | enum "recorded", "rejected" |
      | admittedAt      | instant   | one         | any                         |

  Scenario: Run
    When HTTP "admission" sends "POST" to Environment "admissionUrl" with Input as JSON body and reads JSON
    Then Produce with JSONata
      """
      {
        "admission": input.admission,
        "admissionStatus": steps.admission.body.admissionStatus,
        "admittedAt": steps.admission.body.admittedAt
      }
      """
```

## Résultat

| Champ | Type |
| --- | --- |
| `steps.<name>.status` | number — le code de statut HTTP |
| `steps.<name>.headers` | objet de chaînes (peut être copié en entier, pas traversé) |
| `steps.<name>.body` | string pour `Text`, valeur analysée pour `JSON`, chaîne vide pour `no body` |

Un statut hors de l'ensemble accepté interrompt l'Opération avant Produce. Une panne de transport, un timeout ou un JSON invalide l'interrompt également.

## Authentification

Les headers peuvent utiliser des valeurs d'Environment `string` non secrètes. L'URL elle-même ne
doit porter aucun credential. Les références de credentials ne sont pas exposées comme valeurs
d'Opération et ce contrat HTTP n'injecte pas de headers secrets.

<Details title="Diagnostics propres aux étapes HTTP" expert>
| Message | Cause |
| --- | --- |
| `HTTP "x" requires Environment "e" to be a url` | l'Environment est un `directory` |
| `HTTP "x" uses undeclared Environment "e"` | le nom n'est pas dans la table Environment |
| `HTTP "x" path Input "i" must be one string` | `appending` d'un Input non déclaré, `number` ou `many` |
| `HTTP "x" query/header/body Environment "e" must be a string` | la source de valeur n'est pas un Environment `string` |
| `HTTP "x" method "…" is not registered for application requests` | méthode inconnue, `PRI` ou `*` |
| `HTTP "x" CONNECT accepts headers but no path, query or body` | une phrase CONNECT déclare une clause incompatible |
| `HTTP "x" JSONata body requires one DocString` | projection de requête absente |
| `HTTP status "…" must be terminal: 101 or an integer from 200 to 599` | statut informationnel intermédiaire ou autre valeur invalide |
| `HTTP "x" accepted statuses must immediately follow that HTTP step` | la table de statuts est mal placée |
| `Produce cannot traverse non-JSON HTTP body` | un chemin descend sous du Text ou un corps vide |
</Details>
