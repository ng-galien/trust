---
title: "Connect an agent"
summary: "Package the skill, give it to an agent, engage a live Plan, follow it."
order: 4
---

<Steps>
  <Step title="Run the runtime and the interface">`npm run dev` starts the runtime (`127.0.0.1:4318`); `npm run dev:web` the interface. Publish the Procedures and configure the Environments the agent will need (values: `workspaceRoot`, service URLs…).</Step>
  <Step title="Package the skill">`npm run package:skill` → `packages/trust-runner/dist/skill/trust`: `SKILL.md`, `references/results.md`, `scripts/run.js`, `scripts/mcp-stdio.js`. Give this directory to the agent as its skill.</Step>
  <Step title="Point the Runner at the runtime">Environment variables of the agent's shell if the runtime is not local: `TRUST_RPC_ENDPOINT` (`http://<host>:4318/rpc`), `TRUST_OTLP_ENDPOINT` (`http://<host>:4318/v1/traces`). Nothing else: execution values come from the Environment at admission.</Step>
  <Step title="Give the agent the runtime's MCP tools">The runtime serves MCP on `POST /mcp` (`trust_plan_read`, `trust_check_read`, `trust_procedure_read`, `trust_session_read`, `trust_plan_engage`, `trust_plan_declarations_replace`); the Runner also offers `trust_check_run` over stdio (`scripts/mcp-stdio.js`).</Step>
  <Step title="Engage a live Plan">Sidebar → **Plans** → **Engage a plan**: Procedure, Environment, identifier, root inputs. Hand the agent the Plan (any of its Check URIs, or let it engage through MCP).</Step>
  <Step title="Follow">The Plan page updates live: verdicts, reasons, reopened Checks. The agent reads the Plan after each result and picks the next actionable Check. When the work is done, **Close session**.</Step>
</Steps>
