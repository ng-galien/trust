```gherkin fragment
@trust-dsl:1 @operation:<domain>.<action> @version:<x.y.z> [@x-<key>:<value> …]
Feature: <title>
  [description]

  Background: <name>
    Given Environment              | name | type |                              type: directory | url | string
    And Input                      | input | type | cardinality |               type: string | number | instant | reference · one | many
    And Produced fields            | field | type | cardinality | domain |      domain: any | enum "a", "b"

  Scenario: Run
    When/And Shell "<n>" runs "<exe>" with cwd from Environment "<dir>" [and Input "<in>"]
      | argument | source |                                                     source: literal | Input "<in>" | literal + Input "<in>"
    And Shell "<n>" accepts exits
      | exit code | stdout contains | stderr contains |
    When/And File "<n>" reads "<path>" as Text|JSON from Environment "<dir>" [and Input "<in>"]
    When/And HTTP "<n>" sends "<METHOD>" to Environment "<url>"
      [appending Input "<in>" | literal "<segment>" [and …]…]
      [with query "<name>" from Input|Environment "<name>" | as "<literal>"]…
      [with header "<name>" from Input|Environment "<name>" | as "<literal>"]…
      [with Input as JSON body | with JSONata body | with Text body …]
      and reads JSON|Text|no body
    And HTTP "<n>" accepts statuses | status |
    Then Produce with JSONata
      """ { "<field>": <expression>, … } """
```
