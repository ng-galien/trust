```text
@trust-dsl:1 @procedure:<slug> @version:<x.y.z>
Feature: <title>
  [description]

  Background: Plan context
    Given|And one|many string|number|instant|reference "<role>"
        [declared by agent for "<parent>" | for "<parent>" | for each "<parent>" | fixed as "<value>"]

  @scenario:<slug>
  Scenario: <title>
    [Given|And scenario "<slug>" is validated]…
    Then|And Check "<name>" runs Operation "<domain.action>"
        on [each|all] "<role>" as Input "<input>"
        [using [all] "<role>" as Input "<input>" | using plan as Input "<input>"]…
        [and materializes "<role>" from field "<field>"]…
        and must establish "<success reason>"
      """js
      <boolean expression> || fail(<string expression>)
      """
```

| | |
| --- | --- |
| **Injected roots** | `fact` · `context` · `checks` |
| **Expressions** | strict comparisons, arithmetic, boolean logic, arrays, strings, typed instants, closed `Math` and collection methods |
| **Failure** | `condition || fail(reason)`; guards may be joined with `&&` |
| **Built-in bindings** | `using plan as Input "<input>"` — the Plan identifier, for one `string` or `reference` Input; compiles to a synthesised role `"plan"` with source `plan-identifier` |
