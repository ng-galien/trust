title: "HTTP steps"
summary: "Send a registered HTTP method with structured path, query, headers and content, then read JSON, Text or no body."
order: 3
---

```gherkin fragment title="One sentence for every HTTP method"
    When HTTP "<name>" sends "GET" to Environment "<url>" and reads Text
    And  HTTP "<name>" sends "QUERY" to Environment "<url>" appending Input "<a>" and literal "search" with query "<name>" from Input "<c>" with header "accept" as "application/json" with JSONata body and reads JSON
    And  HTTP "<name>" sends "POST" to Environment "<url>" with Input as JSON body and reads JSON
```

## Request

| Part | Rule |
| --- | --- |
| `"<name>"` | lower camel case, unique in the Operation |
| `sends "<METHOD>"` | one registered application method, including RFC 10008 `QUERY`; `PRI` and the reserved `*` token are not application requests |
| `to Environment "<url>"` | required; the Environment value must be of type `url` |
| `appending Input "<a>"` / `and literal "<segment>"` | optional encoded path segments, in order |
| `with query "<name>" …` | optional and repeatable; value from an Input, a `string` Environment or a literal |
| `with header "<name>" …` | optional and repeatable; value from an Input, a `string` Environment or a literal |
| `with Input as JSON body` | the complete typed Input, encoded as JSON |
| `with JSONata body` | a closed JSONata DocString evaluated immediately before the request; it may read previous steps and use `$assert` to stop before mutation |
| `with Text body …` | Text from an Input, a `string` Environment or a literal |
| `and reads JSON` / `Text` / `no body` | parsed JSON, opaque Text, or an intentionally empty result body |

Clauses are ordered: path, query, headers, optional body, response. Path and query values are
URL-encoded in sentence order. A base URL cannot already contain a query when the sentence declares
one. Header values reject CR, LF and NUL; Text bodies may be multiline. There is no free URL interpolation.

`CONNECT` uses the authority of its Environment URL as the request target and accepts headers but
no path, query or body. Its URL must contain no path or query. The Runner records the handshake and
closes the tunnel because one Operation step is one bounded request.

```gherkin fragment
    When HTTP "issue" sends "GET" to Environment "jiraIssueUrl" appending Input "issue" and reads JSON
    Then Produce with JSONata
      """
      { "issue": input.issue, "summary": steps.issue.body.summary, "workflowStatus": steps.issue.body.workflowStatus }
      """
```

```gherkin fragment title="GET <issuesUrl>/<issue>/comments?limit=5&run=<run>"
    When HTTP "comments" sends "GET" to Environment "issuesUrl"
        appending Input "issue" and Input "resource"
        with query "limit" as "5"
        with query "run" from Input "run"
        and reads JSON
```

## Statuses

The default accepted range is `200`–`299`. An Operation can replace it with exact terminal statuses:

```gherkin fragment
    And HTTP "response" accepts statuses
      | status |
      | 200    |
      | 404    |
```

```gherkin operation id="healthcare.admission-record" title="healthcare.admission-record — POST the Input, read the answer"
# language: en
@trust-dsl:1 @operation:healthcare.admission-record @version:1.0.0
Feature: Record one simulated patient admission

  Background: Operation interface
    Given Environment
      | name         | type |
      | admissionUrl | url  |
    And Input
      | input              | type      | cardinality |
      | patient            | reference | one         |
      | admission          | reference | one         |
      | documents          | reference | many        |
      | documentRecordedAt | instant   | many        |
    And Produced fields
      | field           | type      | cardinality | domain                      |
      | admission       | reference | one         | any                         |
      | admissionStatus | string    | one         | enum "recorded", "rejected" |
      | admittedAt      | instant   | one         | any                         |

  Scenario: Run
    When HTTP "admission" sends "POST" to Environment "admissionUrl" with Input as JSON body and reads JSON
    Then Produce with JSONata
      """
      {
        "admission": input.admission,
        "admissionStatus": steps.admission.body.admissionStatus,
        "admittedAt": steps.admission.body.admittedAt
      }
      """
```

## Result

| Field | Type |
| --- | --- |
| `steps.<name>.status` | number — the HTTP status code |
| `steps.<name>.headers` | object of strings (may be copied whole, not traversed) |
| `steps.<name>.body` | string for `Text`, parsed value for `JSON`, empty string for `no body` |

A status outside the accepted set interrupts the Operation before Produce. Transport failure, timeout and invalid JSON also interrupt it.

## Authentication

Headers can use non-secret `string` Environment values. The URL itself must carry no credentials.
Credential references are not exposed as Operation values, and this HTTP contract does not inject
secret headers.

<Details title="Diagnostics specific to HTTP steps" expert>
| Message | Cause |
| --- | --- |
| `HTTP "x" requires Environment "e" to be a url` | the Environment is a `directory` |
| `HTTP "x" uses undeclared Environment "e"` | the name is not in the Environment table |
| `HTTP "x" path Input "i" must be one string` | `appending` an undeclared, `number` or `many` Input |
| `HTTP "x" query/header/body Environment "e" must be a string` | a value source is not a `string` Environment |
| `HTTP "x" method "…" is not registered for application requests` | unknown method, `PRI` or `*` |
| `HTTP "x" CONNECT accepts headers but no path, query or body` | a CONNECT sentence declares an incompatible clause |
| `HTTP "x" JSONata body requires one DocString` | missing request projection |
| `HTTP status "…" must be terminal: 101 or an integer from 200 to 599` | an interim informational status or another invalid value |
| `HTTP "x" accepted statuses must immediately follow that HTTP step` | the status table is misplaced |
| `Produce cannot traverse non-JSON HTTP body` | a path goes below Text or an empty body |
</Details>
